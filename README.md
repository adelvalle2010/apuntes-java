# Apuntes completos de Java

Página de estudio para **Programación I · 2.º Bachillerato Tecnológico en Informática**: 19 láminas de Java, de lo básico a lo avanzado (JDK/JRE/JVM, variables, control, métodos, arrays, Strings, POO, excepciones, colecciones, Map, JDBC y archivos), con diagramas, animaciones paso a paso, glosario y autoevaluación.

- Sitio: https://adelvalle2010.github.io/apuntes-java/
- Traducido y adaptado de *Java Complete Notes: Beginner to Advanced*, de Achal Singh (@TheAutomationEngineer en Instagram).

Material: Prof. Andrés del Valle
